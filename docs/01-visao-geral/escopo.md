# Escopo do Projeto

## Visão Geral

Este projeto tem como objetivo reunir e organizar exemplos de documentação técnica aplicados ao contexto de desenvolvimento de software.

A documentação será construída de forma incremental durante a formação em Redação Técnica da Alura, utilizando Markdown e GitHub para criação, organização e versionamento do conteúdo.

## Dentro do Escopo

Fazem parte deste projeto:

- Documentação da visão geral do projeto.
- Definição de objetivos e escopo.
- Documentação de requisitos.
- Registro de regras de negócio.
- Documentação de arquitetura e integrações.
- Exemplos de documentação de APIs.
- Estratégias e cenários de testes.
- Critérios de aceite.
- Documentação de operação e troubleshooting.
- Registro da evolução das documentações.

## Fora do Escopo

Neste momento, não fazem parte do projeto:

- Desenvolvimento de uma aplicação funcional.
- Implementação de APIs reais.
- Configuração de infraestrutura.
- Deploy em ambiente produtivo.
- Uso de dados reais ou confidenciais.

## Evolução do Escopo

O escopo poderá evoluir conforme novos conceitos e tipos de documentação forem abordados durante a formação.
